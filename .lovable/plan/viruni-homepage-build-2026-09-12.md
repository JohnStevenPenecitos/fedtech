# Viruni Homepage Build

## What I’ll build
- Replace the placeholder home page with a complete Viruni technology homepage.
- Add a sticky desktop navigation, products mega-menu, and accessible mobile drawer with product accordions.
- Build a four-slide, full-background hero with crossfades, controls, indicators, and staggered copy transitions.
- Add the company introduction, five featured solutions, four benefits, full category grid, contact band, and footer.
- Use cohesive generated technology photography for the hero, introduction, and solution cards.

## Visual direction
- Enterprise-tech editorial style using Viruni navy, teal, mineral gray, and warm off-white.
- Bold geometric typography, crisp grids, restrained glow accents, and subtle circuit/grid details.
- Strong contrast and precise spacing, with layouts tailored for desktop, tablet, and mobile.

## Motion and interactions
- Use GSAP with ScrollTrigger for one-time section reveals, staggered cards and tiles, subtle parallax, and the nav transition.
- Add restrained hover/tap feedback and smooth hero transitions.
- Disable animation for reduced-motion users and simplify expensive effects on mobile.

## Technical details
- Split the page into focused React components and keep all color/font/shadow values in the global design system.
- Add semantic headings and landmarks, keyboard-operable menus and slider controls, alt text, and visible focus states.
- Add route-specific title, description, Open Graph, and Twitter metadata.
- Validate the running page at desktop, tablet, and mobile sizes, including menu and slider interactions.
